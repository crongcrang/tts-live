🔊 TikTok Live TTS (Text-to-Speech) Tool
เครื่องมือนี้เป็นแอปพลิเคชันเดสก์ท็อปที่ใช้ Python และ Tkinter สำหรับเชื่อมต่อกับ TikTok Live Stream และแปลงข้อความคอมเมนต์ให้เป็นเสียงพูดภาษาไทยแบบเรียลไทม์ โดยใช้บริการ Edge TTS ที่มีคุณภาพสูง

🌟 คุณสมบัติหลัก (Features)
🎙️ การแปลงเสียงพูดตามเวลาจริง: แปลงข้อความคอมเมนต์จาก TikTok Live เป็นเสียงพูดภาษาไทยโดยใช้ Edge TTS

🗣️ ตัวเลือกเสียงภาษาไทย: รองรับเสียงคุณภาพสูง 2 เสียงหลัก (Achara Neural - ชาย, Premwadee Neural - หญิง)

🎚️ การปรับแต่งเสียง: สามารถปรับ Pitch (ความทุ้ม/แหลม) และ Speed (ความเร็ว) ของเสียงได้ตามต้องการ

⏯️ Live Control: มีปุ่มควบคุมสำหรับ Pause/Resume TTS และ Skip Comment เพื่อจัดการคิวข้อความอย่างยืดหยุ่น

📊 สถิติเรียลไทม์: แสดงสถานะการเชื่อมต่อ, จำนวนข้อความในคิว, จำนวนข้อความที่อ่านแล้ว, และอัตราการอ่านต่อนาที

🌐 Open Live: ปุ่มสำหรับเปิด Live Video ในเว็บเบราว์เซอร์เพื่อรับชมควบคู่กัน

🎤 Custom TTS: มีแท็บสำหรับทดสอบการตั้งค่าเสียงและสร้างไฟล์ MP3 จากข้อความที่ต้องการ (พร้อมปุ่มดาวน์โหลด)

⬇️ ระบบ Auto-Update (เบื้องต้น): มีเมนูสำหรับตรวจสอบเวอร์ชันล่าสุดและดาวน์โหลดไฟล์อัปเดต (ต้องตั้งค่า URL เอง)

🛠️ ความต้องการ (Prerequisites)
เครื่องมือนี้สร้างขึ้นจาก Python และต้องใช้ไลบรารีบางตัว:

Python: เวอร์ชัน 3.8 หรือสูงกว่า

Pygame: สำหรับการเล่นไฟล์เสียง

TikTokLive: สำหรับเชื่อมต่อและรับข้อมูล Live Stream (Unofficial API)

edge-tts: สำหรับการแปลงข้อความเป็นไฟล์เสียง MP3

requests: สำหรับการตรวจสอบอัปเดต

การติดตั้ง
Bash

pip install pygame TikTokLive edge-tts requests Pillow pystray
🚀 วิธีการใช้งาน (How to Use)
รันโปรแกรม: หากคุณใช้ไฟล์ .exe ที่ถูกคอมไพล์แล้ว ให้ดับเบิลคลิกเพื่อเปิดโปรแกรม

ตั้งค่าเสียง:

เลือกเสียงที่ต้องการ (ผู้ชาย Achara Neural เป็นค่าเริ่มต้น)

ปรับ Pitch (Hz) และ Speed ในส่วนควบคุมด้านบน

ทดสอบ (Optional): ไปที่แท็บ 🎤 Custom TTS ใส่ข้อความ และกด 🔊 Preview เพื่อทดลองฟัง

เชื่อมต่อ Live:

ไปที่แท็บ 🚀 Live Connection

ใส่ชื่อบัญชี TikTok Username ของช่องที่กำลัง Live อยู่

กดปุ่ม Connect

การควบคุม:

ใช้ ⏸️ Pause TTS เพื่อหยุดการอ่านข้อความที่เข้าคิวไว้ชั่วคราว

ใช้ ⏩ Skip Comment เพื่อข้ามข้อความปัจจุบันและอ่านข้อความล่าสุดที่อยู่ในคิวแทน (หรือเคลียร์คิวทั้งหมดหากไม่มีข้อความใหม่)
